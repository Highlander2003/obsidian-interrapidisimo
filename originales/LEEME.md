# Fuentes originales — NO EDITAR

Esta carpeta es la capa inmutable del wiki. Aquí van los originales tal como llegaron:

- `documentos/` — PDF, docx, xlsx, imágenes, capturas.
- `web/` — copias en markdown de páginas web, con la URL y la fecha de consulta en el encabezado.

Reglas:

1. Claude **lee** de aquí y **nunca** modifica, mueve ni borra nada (salvo guardar una copia
   web nueva cuando se lo piden).
2. Todo lo derivado — resúmenes, conceptos, síntesis — vive en `wiki/`.
3. Si un original cambia, se guarda como archivo nuevo con su fecha; no se sobrescribe el anterior.

Las notas de conversación no tienen original: se registran directamente como nota de fuente
con `origen: conversacion`.
